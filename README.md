# Weather App (ASP.NET MVC)

A simple **ASP.NET MVC** web application that allows users to search for the current weather in any city and view detailed weather information in a clean, card-style layout. This app demonstrates the use of **ASP.NET MVC** for building dynamic web applications, fetching real-time weather data from an external API, and displaying it in a user-friendly interface. It covers key concepts like MVC architecture (Model, View, Controller), data binding with Razor syntax, handling user input, displaying dynamic data, and basic front-end styling with CSS, making it a great project for beginners to practice full-stack development.

## Features
- Search weather by city name
- Displays:
  - Temperature (°C)
  - Humidity (%)
  - Pressure (hPa)
  - Weather Condition
  - Wind Speed (m/s)
  - Timezone
  - Current Local Time
- Clean and responsive UI

## Technologies
- ASP.NET MVC, C#
- Models,Views, Controller
- Weather API (e.g., OpenWeatherMap)

## How to Run
1. Clone the repository.
2. Open the project in **Visual Studio**.
3. Restore NuGet packages.
4. Configure API key if required.
5. Run the project.
6. Enter a city name and view weather details.
