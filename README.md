# WeatherApp_ASP.Net_MVC

A simple ASP.NET MVC web application that fetches and displays the current weather information for a given city.

**Features**

1. Search weather by city name.

2. It displays weather details including:

    Temperature (°C)

    Humidity (%)

    Pressure (hPa)

    Weather Condition

    Wind Speed (m/s)

    Timezone

    Current Local Time of the city

3. Responsive and clean UI with styled weather cards.

**Technologies Used**

**Backend:** ASP.NET MVC, C#

**Frontend:** HTML, CSS, Razor Views

**APIs:** Any weather API (e.g., OpenWeatherMap)

**Other:** Model-View-Controller architecture

**Project Structure**

Controllers/ – Handles user requests (WeatherController.cs)

Models/ – Weather data model (Weather.cs)

Views/ – Razor views (Index.cshtml)

Content/ – CSS files

Scripts/ – JS files (if any)
